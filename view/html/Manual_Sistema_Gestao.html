Manual de Uso do Sistema de Gestão Empresarial

Instalação das Dependências

Execute o comando abaixo no terminal para instalar todas as dependências e extensões necessárias:

npm install express mysql multer jsonwebtoken --save-dev nodemon csv-parse axios

Iniciando a Aplicação

Para iniciar o sistema, utilize o comando:

npx nodemon app.js

Acesso ao Sistema

Acesse a rota inicial no navegador:

http://localhost:3000/html/login.html

Conta Padrão (Administrador)

O banco de dados já possui um departamento e um usuário previamente inseridos:(Banco na pagina docs)

  • Departamento: Administração
  • Email: admin@empresa.com
  • Senha: 123

Perspectivas de Usuário

Funcionário

  • Acesso: Apenas login (não pode se cadastrar).
  • Cadastro de Perfil: Após o login, deve preencher:
    • Foto de perfil
    • Dados pessoais
  • Acesso às Informações: Direcionado à página com suas informações dentro da empresa.

Administrador

  • Acesso completo ao sistema.
  • Funcionalidades:
    • Gestão de Funcionários
    • Gestão de Departamentos
    • Visualização de Gráficos e Dashboards
    • Acesso aos Logs do Sistema
    • Cadastro rápido via arquivos .csv
    • Atualização de dados
    • Filtros de busca por nome, cargo e departamento
    • Visualização dos perfis dos funcionários

Dashboards e Gráficos

Na tela inicial do administrador são exibidos:

  • Painéis informativos (dashboards)
  • Quatro botões principais:
    • Gestão de Funcionários
    • Gestão de Departamentos
    • Gráficos
    • Logs

Gráficos disponíveis:

  • Distribuição salarial por departamento
  • Idade média por departamento
